## [0.1.0] - 2026-09-16

- Initial public release.
- Added YAML, JSON, TOML, INI, directory, dynamic-script, and constructed inventory support.
- Added JSON, YAML, and TOML output with graph-aware pruning and strict Ansible compatibility.
- Added differential compatibility tests against ansible-core 2.18.9.
- Added optional OpenTelemetry tracing.
